🚀 Quick Start (3 Steps)

Start Everything in Docker

$ docker-compose up -d

Enter Training Container

$ docker exec -it llmops-training bash

Run Any Module

$ cd 03-scalable-data-preparation $ python3 src/duckdb_elt_pipeline.py $ python3 -m pytest tests/ -v

That's it! Everything runs in Docker. No installation needed.
