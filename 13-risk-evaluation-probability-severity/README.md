# Risk Evaluation: Probability vs Severity

**2×2 matrix, dynamic thresholding, escalation workflows, context-aware routing**

## Learning Objectives

By the end of this module, you will be able to:

  1. Understand 2×2 risk matrix (probability × severity)
  2. Implement dynamic thresholding
  3. Route to escalation for high-severity cases
  4. Avoid false positives on low-severity items

## Duration

2 hours

## Key Concepts & Topics

  • Risk matrix quadrants and actions
  • Probability vs severity distinction
  • Dynamic thresholding logic
  • Escalation workflows
  • Context-aware risk routing
